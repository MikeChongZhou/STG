## P2P 同步加密密钥 bug 修复
- 根因：`SyncSecurity.deriveKey(code, id1, id2)` 需要两个设备的 ID 排序后做 salt
- 但 `p2p-sync-service.ts` 里两个参数都传了本地设备 ID → 每台设备派生出不同密钥
- A 加密的数据 B 解不开（HMAC 校验失败 → 返回 null → 静默丢弃）
- 修复：`getKeyForDevice(remoteDeviceId)` 方法，同步时用双方设备 ID 派生正确密钥
- 同时修复：server 端 handler 用请求头中的远程设备 ID 来加解密
- 版本号统一为 1.0.3（package.json + APP_VERSION + tray + i18n + p2p ping）
